# Inspiration Images

Drop 3 inspiration photos here for the demo. These are user-supplied images and are **not** committed to the repository.

## For testing

Tests use tiny programmatically generated images (created in the test setup) to avoid committing large binary files.

## For the demo

1. Find 3 photos that represent the event vibe (e.g., Udaipur palace decor, outdoor mehendi setup, elegant reception)
2. Place them in this directory as `inspiration-1.jpg`, `inspiration-2.jpg`, `inspiration-3.jpg`
3. The upload flow accepts JPEG, PNG, and WebP (max 5 MB each)
